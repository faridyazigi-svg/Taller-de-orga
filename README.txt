SIMULADOR DE CONCENTRACIÓN DE MERCADO (MONTE CARLO)

REQUISITOS
- Python 3.10 o superior

EJECUCIÓN LOCAL
1. Abrir una terminal en la carpeta del proyecto.
2. Crear entorno virtual:
   Windows:  python -m venv venv  y luego  venv\Scripts\activate
   Mac/Linux: python3 -m venv venv  y luego  source venv/bin/activate
3. Instalar dependencias:  pip install -r requirements.txt
4. Ejecutar:  streamlit run app.py
5. Se abre el navegador en http://localhost:8501

ARCHIVOS
- app.py: aplicación completa
- requirements.txt: dependencias
